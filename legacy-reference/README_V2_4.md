# AaronBux Investing Workflow Prototype V2.4

This version broadens the assessment across people who have not invested yet, simple long-term investors, validation seekers, emerging strategists, and more involved optimizers.

The visible interface does not expose investor-stage, behavioral-modifier, investment-style, or archetype labels. Those remain internal inputs to the resolver. The result translates them into:

- what is unclear in the investor's current process
- what deserves attention
- realistic review rhythm
- which parts can stay simple versus require more effort
- when a change deserves consideration

Run with `python -m http.server 8000` and open `http://localhost:8000`.
