# Architecture

- `src/application`: startup, routing, state.
- `src/features`: user-facing welcome, assessment, and recommendation screens.
- `src/domain`: unchanged V2.4 assessment configuration and equivalent scoring/resolution functions.
- `src/content`: exact V2.4 user-visible copy extracted into data modules.
- `src/shared`: reserved for reusable UI/utilities.
- `assets/css/styles.css`: V2.4 AaronBux design system.
- `assets/css/recommendation.css`: recommendation-only visual refinements.
